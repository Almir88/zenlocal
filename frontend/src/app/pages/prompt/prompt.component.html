Prompt

You describe in plain text what you want in the code, and the AI generates the changes. It uses your GitHub repo: a new branch is created, edits are applied, and a pull request is opened when needed. You can choose to run it via Groq or OpenAI depending on which API key you have in .env. Admins see prompt logs and can add users who can use Prompt as well.

Pick project, AI, type what you want done and optionally a branch name. Hit Run to start.
